# Отчёт по продажам дочерних компаний

Небольшой дашборд на Streamlit. Представим, что есть холдинг и у него пять дочерних
компаний (Канада, Германия, Франция, Мексика и США). Каждая присылает отчёт по продажам
за месяц: сколько продали, со скидкой или без, какая себестоимость и прибыль.
Я собрал это в одно приложение, где можно посмотреть цифры по компаниям, по месяцам,
по продуктам, и проверить, сходятся ли расчёты в отчётах.

## Как запустить

Нужен Python 3.10 или новее.

```
git clone https://github.com/AbdulahadB/sales-dashboard.git
cd sales-dashboard
pip install -r requirements.txt
streamlit run app.py
```

После запуска приложение откроется в браузере (обычно http://localhost:8501).

## Данные

Взял открытый учебный датасет **Financial Sample** от Microsoft (его часто используют
для практики в Excel и Power BI). Скачать можно тут:
https://go.microsoft.com/fwlink/?LinkID=521962

Файл лежит в папке `data/`. В нём 700 строк и 16 колонок, данные с сентября 2013
по декабрь 2014 года, по месяцам.

Основные колонки:

- **Country** – страна, у меня это дочерняя компания
- **Segment** – тип клиента (госсектор, малый бизнес, крупный бизнес и т.д.)
- **Product** – продукт (6 штук)
- **Units Sold** – сколько единиц продали
- **Sale Price** – цена за единицу
- **Gross Sales** – выручка до скидок
- **Discounts** – сумма скидок
- **Sales** – выручка после скидок
- **COGS** – себестоимость
- **Profit** – прибыль
- **Date** – месяц отчёта

## Что сделал с данными

1. Убрал лишние пробелы в названиях колонок (там была колонка `" Sales"` с пробелом в начале).
2. Переименовал колонки, страны и сегменты на русский.
3. В колонке с уровнем скидки было 53 пропуска. Посмотрел на эти строки – там скидка
   равна нулю, поэтому заполнил их значением «Без скидки».
4. Удалил колонку с названием месяца, потому что есть номер месяца и дата.
5. Проверил тип даты и дубликаты (дубликатов нет).

## Что есть в приложении

- Фильтры слева: год, компании, сегмент клиентов
- Главные цифры: выручка, прибыль, маржа, сколько продано
- **Компании** – выручка и прибыль по каждой дочке, маржа и сводная таблица
- **Динамика по месяцам** – как менялись выручка и прибыль
- **Продукты и сегменты** – какие продукты приносят больше прибыли, доля сегментов,
  как скидки влияют на прибыль
- **Таблица** – все данные после фильтров, можно скачать в CSV
